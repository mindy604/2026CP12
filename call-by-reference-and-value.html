Call by Reference
and Call by Value

What can a function change? Follow the names, try a small example, and check what the caller sees afterward.

Watch what changes: the data, or a name?

A parameter is a name used inside a function for the data you pass in. At the start of the call, it refers to that same data. Then watch the function: does it edit the list, or make its local name refer to something else?

Python calls this passing by assignment. The rule is the same for every data type, including strings.

Call by value
The function receives a copy of the value you pass in. Giving the parameter a different value leaves the caller’s variable unchanged. The copied value can itself be an object reference; this does not always copy the object’s contents.

      
Call by reference
The parameter acts as another name for the caller’s variable. Assigning a different value to that parameter can also change the variable outside the function.

      
Python: passing by assignment
The parameter starts as another name for the supplied object. It can change the contents of a shared list. Giving the local name another object leaves the caller’s name referring to its original object.

A list is mutable: you can change its contents while keeping the same list. Integers and strings are immutable: those objects cannot be edited in place. A function may return an answer whether or not it also changes a list.
